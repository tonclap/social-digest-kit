Facebook — сбор ссылок на друзей

У 1424 из 1464 человек в переписи нет ссылки на профиль. Этот скрипт снимает имя и ссылку сразу для всех со страницы списка друзей — один проход вместо полутора тысяч заходов на профили.

  1. Открой facebook.com → свой профиль → вкладка Друзья (адрес вида facebook.com/<твой профиль>/friends).
  2. Нажми F12, вкладка Console. Если Chrome ругается на вставку — напечатай в консоли allow pasting и нажми Enter.
  3. Нажми кнопку ниже, вставь скопированное в консоль, Enter.
  4. Страница начнёт сама прокручиваться и собирать ссылки — это несколько минут, не мешай ей. Когда закончит, браузер сохранит файл fb_friends.json.
Скрипт только читает страницу и прокручивает её. Ничего не публикует, никуда не отправляет, файл сохраняется тебе в загрузки. Прокрутка идёт человеческим темпом — Facebook такое поведение не отличает от обычного просмотра списка друзей.
